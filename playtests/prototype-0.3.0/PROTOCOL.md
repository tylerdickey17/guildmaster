# Independent simulation protocol

Frozen pack 0.3.0: `values.json` and `../../docs/prototype-values-v0.3.md`. Do not modify either during testing. Each agent writes only its own named files in this directory. Root owns `simulator.py`, `verify.py` and consolidated report. Root will publish engine coverage and limitations. All agents may call its pure mission/economy helpers after available; independent exact computations are encouraged as an oracle.

Six assignments: mission probabilities/adversarial deployments; new-guild 12-month acquisition A/B; established/large-guild capacity/economy; training/progression; debt/distress/property; loyalty/rival/trained-action economics. Every agent reports assumptions, seeds, sample counts, observed evidence, interpretation and recommendations separately. Report numerical alternate values as sensitivities, never alterations to 0.3.0.

Use at least 1,000 campaign trials for estimated campaign probabilities, or exact enumeration for mission probabilities. Exact three-phase enumeration is 20^3=8,000 equiprobable paths and includes forward effects. Monte Carlo intervals: Wilson 95% for binary proportions. Quantiles are empirical order statistics; give means plus 10th/50th/90th percentiles for money. Record one fully reproducible monthly trace seed7. Use common per-turn keyed random draws for paired A/B rather than a single stream shifted by divergent action counts. Independent agents may use explicitly disclosed alternate RNG for independent cross-checking.

Baseline qualified balanced squads have relevant high phase leads and every other member relevant trained-or-better support. This is a **favorable coverage fixture**, not the claim that every generated mercenary knows every skill. Test ordinary/moderate or sparse support sensitivities. Repeatability/powergaming, actual fixed mission level, payroll at departure, receipt-before-bills, onboarding, recovery, one new job/member/turn and next-turn capacity must be respected. No action cost disappears except a stated variant or feat.

Simulated strategic policies and exogenous boards/events are test fixtures, not emergent human decisions. Distinguish a saturated replenishing offer deck from the playable limited starting board. No simulated live table time, enjoyment or universal balanced claim. Publish unresolved mechanics/coverage omissions explicitly; use authored manual probes where the engine does not implement a feature.

Recommended tuning is grounded in a comparison or arithmetic bound, not just preference. Preserve user decisions (three checks, equal XP, floor average, choice of failed pay, two-action officer baseline, trained gate, 1–20 mercenaries, monthly clocks). Report what numerical change could fix a demonstrated issue before changing a procedural rule. Do not add bonus mission rolls.
