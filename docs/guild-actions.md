# Guild Action catalog

Status: accepted names and conceptual purposes, October 10, 2026. See the [integration checkpoint](integration-checkpoint.md) for timing and the [decision log](design-decisions.md) for INT-016.

Every Guild Action needs an available PC/NPC officer and uses the shared level-based action pool. The provisional officer limit is two per turn. Basic actions are intended to remain accessible to any available eligible officer; trained actions require the listed proficiency. No Expert-tier action catalog is adopted.

**Costs:** Secure Contract and Recruit Operative are confirmed at one action each. Other listed actions use the proposed one-action starting baseline pending explicit cost design/playtesting. Exact effects, resources, DCs, durations, eligibility, repeat limits, and costs are not invented here.

## Basic actions

| Action | Purpose and boundary |
| --- | --- |
| Secure Contract | Acquire an available contract; one action. Deployment and ongoing resolution are routine, without another action. Acquisition versus free acquisition is an A/B subject. |
| Work the Network | Generate contract leads or recruitment candidates. Recruitment uses Diplomacy and yields 0/1/2/3 candidates by degree. Finding and securing/hiring are separate. |
| Recruit Operative | Hire one available candidate; one action. Hiring terms and onboarding timing still apply. |
| Run Training Drills | Begin training eligible personnel. One turn by default; continued consecutive training can earn a bonus, values deferred. |
| Promote the Guild | Modestly improve public reputation through outreach/publicity/service. |
| Boost Morale | Invest in personnel loyalty through recognition/support/team development. |
| Establish Relations | Improve relations with another guild or organization. |
| Appoint Officer | Hire an outside officer or promote an eligible existing member. |
| Commission Project | Begin construction, an upgrade, or property expansion. Ongoing progress is automatic; manager remains committed. Repair scope remains conditional on adopting the provisional damage/repair system. |
| Secure Financing | Apply for borrowing/refinancing, subject to lender approval and debt requirements. |
| Negotiate Property Deal | Buy, lease, or sell property, subject to transaction terms. |

Strategic actions can modestly improve relevant metrics but do not bypass funding, proficiency, personnel, or approval requirements. Contracts and meaningful development remain the primary progression sources.

## Trained actions

The user accepted all nine conceptual actions and these proposed skill requirements, retaining only Trained requirements for now.

| Action | Requirement | Intended benefit, not yet numeric |
| --- | --- | --- |
| Broker Exclusive Deal | Trained Diplomacy | Pursue a limited-window exclusive offer. |
| Analyze Market Data | Trained Society or relevant Lore | Target leads toward a category/region. |
| Conduct Digital Recon | Trained Computers | Investigate a client, rival, or site for useful information/warnings. |
| Run Counterintelligence | Trained Computers or Deception | Protect against a particular rival's intelligence/interference. |
| Coordinate Joint Operation | Trained Diplomacy | Negotiate help from a Friendly/Allied guild on particular work. |
| Establish Recovery Protocol | Trained Medicine | Organize treatment and potentially shorten eligible recovery with resources. |
| Optimize Infrastructure | Trained Crafting | Temporarily improve property maintenance/project efficiency. |
| Plan Logistics Corridor | Trained Piloting or Survival | Establish a route benefiting qualifying transport/deployments in a region. |
| Launch Media Campaign | Trained Performance or Diplomacy | Pursue targeted publicity, client attraction, or scandal response. |

Proficiency is an access requirement, not an automatic guaranteed bonus or success. No new roll is inserted into Standard Contract resolution. Action-specific checks and benefits remain to be authored.

## Accepted relocation action and additional proposals

**Relocate Operations** is accepted through INT-009: initiate headquarters/facility relocation, observing Transferable N, slots, lease restrictions, and inactive transfer time. Its one-action cost remains the starting proposal; no additional actions are spent just to advance an existing transfer.

Gather Intel, Provide R&R, Reorganize Command, and Renegotiate Terms were proposed earlier but were not individually finalized. Keep them as optional catalog candidates rather than silently treating all five earlier suggestions as approved. Distinguish general Gather Intel from trained technical investigation, Provide R&R from medical recovery, and ordinary lease/contract renegotiation from Secure Financing.

Expert-level Negotiate Retainer and Establish Intelligence Network are explicitly deferred. Action-free recurring-client benefits are accepted as a progression concept, not as an adopted Expert action.

## Automatic/routine operations

No Guild Actions for payroll, overhead, debt repayments, continuing approved construction, ongoing training/transfer progress, deploying an available squad on an accepted contract, or resolving a previously deployed contract. These retain money, time, staffing, recovery, eligibility, and three-check requirements.

Commerce actions consume the same shared pool before Activity. A free immediate event decision does not grant a free basic action unless the event's terms expressly waive it.

## Playtest boundaries

Matched acquisition A/B: one action to secure a Standard contract versus free securing, with deployment free in both. Hold initial resources, roster, officer capacity, contracts, events, and action pool constant. Compare strategic crowd-out, interesting tradeoffs, deploy-on-every-job incentives, workload, and elapsed live table time. Officer capacity starts at two; one versus two can be tested separately.

Three starting shared actions was an assistant suggestion only. No shared actions-by-level schedule is approved.
